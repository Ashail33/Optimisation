Leaderboard

Rank: each optimiser is ranked by normalised gap on every task (problem instance × budget, averaged over repeats); the rank is rescaled to 0 = best … 1 = worst among the optimisers that ran on that task, then averaged. Score = 1 − gap, where gap 0 is the optimum (or best-known) and gap 1 is no better than random sampling. Optimisers that only cover some tasks (e.g. permutation-only) are listed after full-coverage ones. Click a column to sort.

Precision per problem

Each cell is an optimiser's mean normalised gap on one problem instance, binned by order of magnitude (stronger colour = closer to the optimum). Rows are ordered by rank. Empty cells: the optimiser cannot solve that encoding. Hover or focus a cell for exact values.
